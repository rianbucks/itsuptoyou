# 인물 선정 기준

## 필수 조건 [확정]
- 이미 사망한 인물
- 국가 단위 이상, 나아가 전 세계에 영향을 미친 인물
- 세계적인 역사 사료에서 한평생을 파악할 수 있는 인물

## 평가 기준 (각 1~5점) [확정, 점수화는 제안]
| 코드 | 기준 | 판단 질문 |
|---|---|---|
| C1 | 결정적 양갈래 길 | 선택에 따라 역사가 갈렸다고 볼 수 있는 분기점이 10개 가까이 있는가? |
| C2 | 거시적 나비효과 | 2026년 현재까지 이어지는 영향이 명확한가? |
| C3 | 사료 완결성 | 출생부터 사망까지 연대기를 사료로 재구성할 수 있는가? |
| C4 | 인지도·몰입감 | 설명 없이도 흥미를 끄는 인물인가? |
| C5 | 다양성 기여 | 시대·분야·대륙 분포에서 빈 곳을 채우는가? |

## 문명/대륙 쿼터제 [확정]
유럽·미국 편중을 막고, 한국·일본·중국·인도 등 다양한 문명권 인물을 균형 있게 배치한다.
- 사용자 예시: 한국(세종, 이순신, 고종), 일본(오다 노부나가), 중국(진시황), 인도(아쇼카왕)
- **[미정]** 대륙·분야별 구체적 인원 배분

## 분야 다양성 [확정]
군주·장군 편중을 막는다. 후보 분야: 군주, 군인, 정치가, 사상가·종교 지도자, 과학자·발명가, 예술가, 탐험가, 대중문화인

## 위험 검토 항목 [제안]
| 항목 | 질문 |
|---|---|
| R1 법적 | 나치 상징 규제, 사후 퍼블리시티권, 이미지 저작권 문제가 있는가? |
| R2 윤리 | 학살·박해를 플레이어 목표로 만들 위험이 있는가? |
| R3 사생활 | 결정적 선택이 공적 행위가 아니라 사생활에 가까운가? |
| R4 여론 | 해당 인물로 콘텐츠를 만들었을 때 유가족이나 관련 단체의 부정적 여론이 심한가? 심하면 최대한 배제한다. |

- **[확정]** 최근 사망 인물은 기간 제한 없이 R1·R3·R4로 인물별 검토한다(GDD §7).
- **[확정]** R4는 최근 사망 인물에만 적용한다(저작권 침해·소송 위험 때문).
- **[제안]** 최근 사망 인물 = 사망 후 70년이 지나지 않은 인물.
- R2는 제외 기준이 아니다. 해당하면 악영향 코멘트와 결말 규칙(GDD §5·§7) 적용 대상으로 표시한다.
